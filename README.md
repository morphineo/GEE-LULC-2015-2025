#Southwest Mau Forest Cover Change (2015–2025)
This project assesses land-cover dynamics in the Southwest Mau Forest, Kericho County, Kenya, between 2015 and 2025, with particular focus on indigenous forest change and the pressures affecting the surrounding landscape.
#Methodology
- Processed multi-temporal Sentinel-2 imagery in Google Earth Engine.
- Developed a 16-feature dataset using spectral bands, vegetation indices and topographic variables.
- Classified seven land-cover classes using Random Forest.
- Evaluated classification accuracy using independent validation points, confusion matrices and Kappa statistics.
- Analysed land-cover transitions using post-classification change detection and transition matrices.
3Key Findings
- Classification accuracy ranged from 91.5% to 95.0%.
- Indigenous forest recorded a net gain of 1,048.65 ha (15.20%).
- Wetland area declined by 59.94%.
- Built-up land expanded by 232.68 ha.
- Forest gains occurred alongside continued conversion of indigenous forest and transitional vegetation to agricultural and built-up land.
#Recommendations
The study highlights the need to protect transitional vegetation, restore wetlands in the Sondu-Miriu watershed and strengthen community-based forest management.

Tools: Google Earth Engine, Python, Google Colab, Sentinel-2, Random Forest, GIS and remote sensing.
